Elementor Addons for PubCrawls — provides 24 native Elementor widgets for Events, Cities, Venues, FAQs, Maps, Agendas, Eventbrite & SquadUp Tickets, AI Quick Links, and dynamic content. Fully replaces both `pub-crawls` and `pubcrawls-eventbrite-tickets`.

== Description ==

Pubcrawl Addon is the complete, standalone Elementor solution for PubCrawls. It replaces both the legacy `pub-crawls` plugin and the `pubcrawls-eventbrite-tickets` plugin with 24 intuitive, high-performance, and fully customizable Elementor widgets, native custom post types, taxonomies, and shortcodes.

= Included Widgets =
1. **Cities Card Grid** (`pc-cities-card`) — Displays a grid of cities with upcoming event count badges.
2. **Cities List** (`pc-cities-list`) — Displays a directory of popular and all cities with tabbed view.
3. **City Archive Highlights** (`pc-city-archive-highlights`) — Dynamic highlights list for city archives.
4. **City Archive List** (`pc-city-archive-list`) — City archive text list with counts.
5. **City Archive Cards (v2)** (`pc-city-archive-v2`) — Modern card layout for city archives with count badges.
6. **City Archive Grid** (`pc-city-archive`) — Grid layout for city archives filtered by category or IDs.
7. **City Events Grid** (`pc-city-events`) — Grid of upcoming events with dates, image, and buy/info buttons.
8. **City Map** (`pc-city-map`) — Embedded Google Map from city ACF map_url.
9. **City Venues** (`pc-city-venues`) — Participating venues list for a city with directions links.
10. **Event Agenda** (`pc-event-agenda`) — Event timeline / agenda steps from ACF repeater.
11. **Event Booking Deadline** (`pc-event-booking-deadline`) — Dynamic booking deadline for the current event.
12. **Event Cities** (`pc-event-cities`) — City tag or pill display for an event.
13. **Event Date** (`pc-event-date`) — Dynamic formatted event date badge.
14. **Event Sticky Ticket Bar** (`pc-event-sticky`) — Sticky bottom/floating bar with date selector and Eventbrite/SquadUp ticket trigger. Replaces `[pubcrawls_event_sticky]`.
15. **Event Tickets Card** (`pc-event-tickets`) — Main event tickets card with date/time, dropdown date selector, Eventbrite modal & SquadUp checkout integration. Replaces `[pubcrawls_event_tickets]`.
16. **Event Venues** (`pc-event-venues`) — Participating venues list for an event.
17. **FAQ Grid** (`pc-faq-grid`) — FAQ grid filtered by category or limit.
18. **Get Directions Button** (`pc-get-directions`) — Google Maps directions link based on ACF address field.
19. **Job Cities** (`pc-job-cities`) — Job cities taxonomy terms display.
20. **Next Event Date** (`pc-next-event-date`) — Formatted next event date calculation for menus or banners.
21. **Page / Post FAQs** (`pc-page-faqs`) — Dynamic FAQs from ACF repeater 'faqs' on current page, post, or taxonomy term. Replaces `[pubcrawl_page_faqs]`.
22. **Post Content Dynamic** (`pc-post-content-dynamic`) — Dynamic post content renderer.
23. **Social Share URLs** (`pc-social-share`) — Social share links for Facebook, Twitter/X, LinkedIn, or current URL.
24. **AI Quick Links** (`pc-ai-quick-links`) — Direct query buttons for ChatGPT, Perplexity, Google AI, and Microsoft Copilot with inline SVGs and custom styling.

== Installation ==

1. Upload the `pubcrawls-addon` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. You can safely deactivate and remove both `pub-crawls` and `pubcrawls-eventbrite-tickets`.
4. Edit any page with Elementor to find the "PubCrawls" widget category in the editor panel.
